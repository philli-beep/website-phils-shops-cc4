# Phils Shops – Website mit Backend

Inhalt:
- public/index.html – die Website
- netlify/functions/api.mjs – Server-Teil (speichert Daten, prüft das Passwort)
- netlify/lib/core.mjs – Regeln: wer was lesen und schreiben darf
- netlify.toml und package.json – Einstellungen für Netlify

Wichtig: Beim Hochladen auf GitHub müssen die Ordner genau so erhalten bleiben.
Bei Netlify muss die Umgebungsvariable ADMIN_PASSWORD gesetzt werden (dein Admin-Passwort).
